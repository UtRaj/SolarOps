# Database Schema (PostgreSQL + TimescaleDB)

## Transactional Schema (PostgreSQL)

### 1. `grid_stations`
- `id` (VARCHAR PK, e.g. "GS-01", "GS-02")
- `name` (VARCHAR NOT NULL)
- `solar_capacity_kw` (FLOAT NOT NULL)
- `base_load_kw` (FLOAT NOT NULL)
- `live_generation_kw` (FLOAT NOT NULL)
- `grid_export_kw` (FLOAT NOT NULL)
- `created_at` (TIMESTAMPTZ)
- `updated_at` (TIMESTAMPTZ)

### 2. `solar_farms`
- `id` (INTEGER PK)
- `grid_station_id` (VARCHAR FK -> grid_stations.id)
- `name` (VARCHAR NOT NULL)
- `capacity_kw` (FLOAT NOT NULL)
- `base_capacity_kw` (FLOAT NOT NULL)
- `efficiency` (FLOAT NOT NULL)
- `status` (VARCHAR NOT NULL)
- `orientation` (VARCHAR NOT NULL)
- `panel_count` (INTEGER NOT NULL)
- `scale_multiplier` (FLOAT NOT NULL)

### 3. `bess_units`
- `id` (VARCHAR PK, e.g. "BESS-01")
- `name` (VARCHAR NOT NULL)
- `total_capacity_kwh` (FLOAT NOT NULL)
- `current_stored_kwh` (FLOAT NOT NULL)
- `soc` (FLOAT NOT NULL)
- `charge_rate_kw` (FLOAT NOT NULL)
- `discharge_rate_kw` (FLOAT NOT NULL)
- `state` (VARCHAR NOT NULL: 'charging' | 'discharging' | 'standby')
- `temp_c` (FLOAT NOT NULL)

### 4. `battery_packs`
- `id` (INTEGER PK)
- `serial_number` (VARCHAR UNIQUE)
- `soc` (FLOAT NOT NULL)
- `capacity_kwh` (FLOAT NOT NULL DEFAULT 300)
- `soh` (FLOAT NOT NULL)
- `charging` (BOOLEAN NOT NULL)
- `slot_number` (INTEGER)
- `charge_rate_kw` (FLOAT NOT NULL)
- `temp_c` (FLOAT NOT NULL)

### 5. `trucks`
- `id` (INTEGER PK)
- `name` (VARCHAR NOT NULL)
- `plate` (VARCHAR NOT NULL UNIQUE)
- `soc` (FLOAT NOT NULL)
- `battery_capacity_kwh` (FLOAT NOT NULL)
- `payload_capacity_kg` (FLOAT NOT NULL)
- `op_status` (VARCHAR NOT NULL)
- `lat` (FLOAT NOT NULL)
- `lng` (FLOAT NOT NULL)
- `connected_to_charger` (BOOLEAN NOT NULL)
- `charger_bay` (INTEGER)
- `charge_rate_kw` (FLOAT NOT NULL)
- `arrival_soc` (FLOAT)
- `total_deliveries_completed` (INTEGER NOT NULL DEFAULT 0)

### 6. `chargers`
- `id` (INTEGER PK)
- `bay_number` (INTEGER NOT NULL)
- `type` (VARCHAR NOT NULL: 'fast_dc' | 'slow_ac')
- `max_power_kw` (FLOAT NOT NULL)
- `current_power_kw` (FLOAT NOT NULL DEFAULT 0)
- `occupied` (BOOLEAN NOT NULL DEFAULT FALSE)
- `truck_id` (INTEGER FK -> trucks.id)

### 7. `delivery_points`
- `id` (INTEGER PK)
- `name` (VARCHAR NOT NULL)
- `code` (VARCHAR NOT NULL UNIQUE)
- `type` (VARCHAR NOT NULL)
- `lat` (FLOAT NOT NULL)
- `lng` (FLOAT NOT NULL)
- `distance_from_depot_km` (FLOAT NOT NULL)

### 8. `orders`
- `id` (VARCHAR PK)
- `customer_name` (VARCHAR NOT NULL)
- `customer_phone` (VARCHAR)
- `status` (VARCHAR NOT NULL: 'Pending' | 'Scheduled' | 'In Transit' | 'Delivered' | 'Cancelled')
- `origin_point_id` (INTEGER NOT NULL FK -> delivery_points.id)
- `scheduled_pickup_time` (VARCHAR NOT NULL)
- `service_type` (VARCHAR NOT NULL)
- `total_weight_kg` (FLOAT NOT NULL)
- `total_distance_km` (FLOAT NOT NULL)
- `total_fare` (FLOAT NOT NULL)
- `gst_amount` (FLOAT NOT NULL)
- `assigned_truck_id` (INTEGER FK -> trucks.id)
- `created_at` (TIMESTAMPTZ)
- `delivered_at` (TIMESTAMPTZ)

### 9. `order_stops`
- `id` (SERIAL PK)
- `order_id` (VARCHAR FK -> orders.id)
- `stop_order` (INTEGER NOT NULL)
- `delivery_point_id` (INTEGER NOT NULL FK -> delivery_points.id)
- `cargo_weight_kg` (FLOAT NOT NULL)
- `box_count` (INTEGER NOT NULL)
- `leg_distance_km` (FLOAT NOT NULL)
- `leg_fare` (FLOAT NOT NULL)

### 10. `alerts`
- `id` (VARCHAR PK)
- `type` (VARCHAR NOT NULL: 'LOW_SOC' | 'THERMAL' | 'OVERLOAD' | 'BAY_LIMIT' | 'SOLAR_FAULT')
- `severity` (VARCHAR NOT NULL: 'CRITICAL' | 'WARNING' | 'INFO')
- `status` (VARCHAR NOT NULL: 'OPEN' | 'ACKNOWLEDGED' | 'RESOLVED')
- `title` (VARCHAR NOT NULL)
- `message` (TEXT NOT NULL)
- `entity_type` (VARCHAR NOT NULL)
- `entity_id` (VARCHAR NOT NULL)
- `created_at` (TIMESTAMPTZ)
- `resolved_at` (TIMESTAMPTZ)

### 11. `outbox_events`
- `id` (UUID PK)
- `event_type` (VARCHAR NOT NULL)
- `aggregate_type` (VARCHAR NOT NULL)
- `aggregate_id` (VARCHAR NOT NULL)
- `payload` (JSONB NOT NULL)
- `published` (BOOLEAN NOT NULL DEFAULT FALSE)
- `created_at` (TIMESTAMPTZ NOT NULL DEFAULT NOW())
- `published_at` (TIMESTAMPTZ)
